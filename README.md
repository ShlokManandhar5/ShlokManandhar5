### 📌 Featured Project

**[Golang CI/CD Pipeline — Jenkins + Docker + Kubernetes + Argo CD](https://github.com/shlokmanandhar5/YOUR-REPO-NAME)**

An end-to-end automated deployment pipeline for a Go application, demonstrating a full CI + GitOps workflow:

- Jenkins polls Git (`H/5 * * * *`), builds a Docker image, and pushes it to Docker Hub
- Jenkins updates the image tag in a separate Kubernetes/GitOps repo (`deploy.yaml`) and pushes the change
- Argo CD watches the Kubernetes repo and automatically syncs the cluster to the new desired state
- Two-repo separation (app/CI vs. Kubernetes manifests) for clean GitOps boundaries
